# `pixel-music-mv` 迭代日志 (Changelog)

每次在新歌曲实战或用户美学反馈中发现不足，均将改进写入本日志并同步更新规则文档：

- **v1.0（《陀飞轮》经验）**：确立「前 5s 强悬念钩子 + 17 阶段人生心跳兑换进度 + 满格背包彩蛋 + 反向卸甲 True Ending」叙事框架；验证通过 `render.mjs` 一键工具包跨平台打包方案。
- **v2.0（《风之海》经验）**：升级 32-bit 定制像素底图（20 张）与 `drawCloudWipe()` 连续动态转场；验证过长间奏/尾奏裁切与人物踩实地面坐标校准方法。
- **v3.0（《向阳而生》第一次试看教训）**：发现连续多个关卡都采用“跳云台/跳青苔石阶”极度同质化，且普通 DJ 版 MP3 歌词节奏错乱。升级确立：**先做歌词背景与玩法规划文档、再生成逐句提示词、严禁重复跳台机制**。
- **v4.0（《向阳而生》FLAC 重制版 +《沙龙》《浮夸》重构经验）**：
  - 修复旧版 Chrome `page.screenshot()` 拼块撕裂与小字号整数取整导致的弹幕晃动问题，定型 **`imageSmoothingEnabled = true` + 浮点坐标 + 26px 暗色毛玻璃气泡** 标准弹幕组件；
  - 彻底清除《沙龙》《浮夸》中遮挡画面的大块静态对话框，改用追踪框、镜面分裂、弹反波、滑轨飞行、十倍残影等直观动作演出；
  - 修复音频采样率与 256k AAC 无损母带封装规范。
- **v5.0（当前版本）**：废弃按单曲分裂维护的 `tourbillon-mv` / `wind-sea-mv` / `salon-mv` / `lyric-narrative-planner` / `pixel-game-mv-creator` / `music-mv`，统一合并为单一可迭代核心 Skill **`pixel-music-mv`**。
