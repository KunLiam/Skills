# 五大曲风与叙事原型分类库（按歌曲气质选用，不限单曲）

遇到新歌时，先听懂词意与编曲情绪，归入以下核心原型并设计**首尾呼应闭环**：

---

## 类型 A：励志治愈探索型（成长 / 光芒 / 自由）
- **适用气质**：宏大交响渐强、由暗转明、自然生命意象（代表作：《向阳而生》《风之海》）。
- **视觉主轴**：永夜苔林 / 迷雾古桥 / 晨曦草甸 / 云海 / 向日葵海。
- **核心演出**：提灯驱暗、踏步绽花、乘翼穿环、护盾弹反、篝火淬炼、结尾星海日出。

## 类型 B：人生哲理交互 RPG 型（时间 / 得失 / 反思）
- **适用气质**：叙事跨度大、现实讽刺与人生回望（代表作：《陀飞轮-抖音》）。
- **核心架构**：`LV.18 → LV.55` 档案建档 → 青春海滨滑板捡快乐 → 写字楼加班爬升职阶梯 → 炫耀清单打勾 vs 生命心率倒计时 → **反向真结局**（卸下所有名表豪宅换回宁静日出）。

## 类型 C：悬疑剧情摄影型（记忆 / 时光 / 都市电影）
- **适用气质**：细水长流、胶片质感（代表作：《沙龙》）。
- **核心演出**：旧照悬念 → 动态追焦合焦吐出拍立得 → 雨水擦镜 → 暗房四格显影 → 结尾底片画廊回望。

## 类型 D：戏剧张力逆袭型（孤独 / 抗争 / 嘶吼）
- **适用气质**：强冲突、压抑爆发与反差落泪（代表作：《浮夸》）。
- **核心演出**：`LV.01 透明人` 躲避追光灯 → 镜面双生对照（台前狂舞 vs 后台落泪）→ 撞碎忽视墙站上中心舞台 → 熄灭激光留天光独白。

## 类型 E：温柔共鸣心事 RPG 型（情绪关怀 / 孤独治愈 / 微光救赎）
- **适用气质**：温柔钢琴起步、副歌情感爆发、直击现代人内心孤独或抑郁心境（代表作：《好想爱这个世界啊》）。
- **核心架构（全曲共情闭环）**：
  1. **柔和曲名序幕（0–3s）**：深蓝夜雨星光中淡入歌名与献辞，柔和过渡进入主角《今日心事》状态档案（如“微笑电量 18%”）。
  2. **具象贴词微日常**：沙发抱枕与百叶窗微尘、落日老影院白日梦落空、屋檐电线黑鸦的刺耳议论、雨夜公交站面对热闹世界按下违心的`▶ “我挺好的呀”`。
  3. **低谷拉一把与独木桥抉择**：暴雨海岬电量跌至 2% 时迎来提灯同伴“还有我在”；拥挤独木桥上选择“不推开任何人、守住自己的温柔”。
  4. **首尾闭环终局**：从片头孤零零昏暗沙发＋无人接听手机，到片尾推开夕阳窗帘接通“最重要的人”的来电、`微笑电量 100%` 温柔落幕。
