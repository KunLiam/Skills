# 四大曲风与叙事原型分类库（按歌曲气质选用，不限单曲）

遇到一首新歌时，先听懂词意与编曲情绪，归入以下 4 类核心原型之一（或组合使用）：

---

## 类型 A：励志治愈探索型（成长 / 光芒 / 自由）
- **适用曲目气质**：宏大交响渐强、由暗转明、自然生命意象（参考作品：《向阳而生》《风之海》）。
- **视觉主轴**：永夜苔林 / 迷雾海崖 / 萤火古桥 / 晨曦草甸 / 云海 / 向日葵海 / 永恒圣殿。
- **核心悬念**：收集 X 枚失落光明信物（太阳碎片 / 风之记忆）破除暗影、迎回白昼。
- **典型玩法组合**：
  1. 提灯驱暗唤醒金芽罗盘；
  2. 踏步绽放花径 + 护盾精准弹反 Boss 音爆弹幕；
  3. 音游节拍环点灯 + 灵兽同伴并肩挡风；
  4. 乘光翼贴海滑翔 / 踏浪冲浪 + 蓄力日光炮清屏；
  5. 篝火营地淬炼武器升级 + 全员极光支援 Boss 战 + 结尾星海致敬歌迷（主角名若为华晨宇风格可加 `yu` 后缀，如 `追光者yu`）。

---

## 类型 B：人生哲理闯关型（时间 / 得失 / 反思）
- **适用曲目气质**：叙事年代跨度大（18 岁 → 38 岁 → 55 岁）、现实共鸣与反讽（参考作品：《陀飞轮》）。
- **视觉主轴**：钟表作坊 / 维港青春 / 深夜写字楼 / 半山豪宅 / 摩天高塔 / 黄昏斜坡 / 怀表星海。
- **核心悬念**：用剩余心跳兑换世俗奢侈品（手表 / 头衔 / 房子）→ 发现生命倒计时归零危机 → 反向觉醒结局。
- **典型玩法组合**：
  1. 玩家年龄/心率 RPG 档案建档（`LV.18 → LV.55`）；
  2. 青春跑酷拾取理想信物（旧磁带机）；
  3. 加班砍碎 `[急件 DDL]` / `[KPI]` 砖块 + 开箱 `SSR` 奢侈品；
  4. 满足度暴跌反转 + 心跳交换发票逐张打印；
  5. 满格背包彩蛋（落灰的旧梦想）→ **反向玩法（TRUE ENDING）**：在巅峰主动卸下所有虚荣装备换回平静日出。

---

## 类型 C：悬疑剧情摄影型（记忆 / 时光 / 艺术日常）
- **适用曲目气质**：细水长流、胶片感、都市温柔记录（参考作品：《沙龙》）。
- **视觉主轴**：老照相馆 / 叮叮车站 / 雨夜骑楼 / 落日天桥 / 天星小轮 / 烟火摩天轮 / 红灯暗房 / 个人影展。
- **核心悬念**：一卷只有 N 格的旧胶卷 + 匿名旧照，收集 4 条时空线索，解开最后一张底片的秘密。
- **典型玩法组合**：
  1. 匿名信 + 撕裂拍立得引入；
  2. 移动取景框自动追焦（失焦虚化 → 绿框合焦快门闪白弹出实景拍立得）；
  3. 雨水擦镜还原回忆 + 黄金分割九宫格构图；
  4. 四色情绪长曝光光绘 + 售罄翻口袋隐藏底片反转；
  5. 闪光灯静止时钟 + 暗房四格药水显影 + 结尾实景底片画廊漫步。

---

## 类型 D：戏剧张力逆袭型（孤独 / 抗争 / 破圈嘶吼）
- **适用曲目气质**：强冲突、压抑爆发、摇滚/癫狂呐喊与反差落泪（参考作品：《浮夸》）。
- **视觉主轴**：孤单天台 / 无人地铁站 / 聚光大礼堂 / 霓虹窄巷 / 化妆镜后台 / 屋村长廊 / 万人体育馆。
- **核心悬念**：`LV.01 透明人（存在感 0%）` 在冷漠人潮中冲破沉默，迎着嘘声风暴站上中心舞台。
- **典型玩法组合**：
  1. 追光灯躲猫猫扑空 + 樽盖气压飙升 100% 全屏震波爆破；
  2. 四面台一键闪耀变装 + 插袋快门定格；
  3. 斩碎「木头」「石头」标签 + **镜面双生对照**（台前狂舞 vs 镜内哭泣）；
  4. 撞碎「忽视」重压墙 + 万人荧光棒随拍点亮；
  5. 十倍苦心残影练舞 + 红区嘘声弹幕声波清屏 + 结尾熄灭激光唯留一束天光独白。
