# 六大曲风与叙事原型分类库（覆盖任意歌曲与词意）

收到任何新歌时，先读懂歌词核心冲突与编曲情绪弧线（前奏 -> 主歌 -> 预副歌 -> 副歌 -> 桥段高音 -> 尾奏），归入以下原型之一，**严禁千篇一律套用“抑郁房间”或“跑酷打怪”**：

---

## 类型 A：励志成长探索型（光明 / 破茧 / 自由冒险）
- **适用曲风**：史诗流行、交响渐强、热血治愈（如《向阳而生》《风之海》）。
- **视觉主轴**：永夜苔原 -> 迷雾古桥 -> 云海踏步 / 乘风廊道 -> 向日葵海与晨曦日出。
- **核心演出**：提灯驱散迷雾、随节拍踩步开花、风环滑翔、迎风破壁，避免机械连跳同一云台。

## 类型 B：人生哲理交互 RPG 型（时间 / 得失 / 职场与成长）
- **适用曲风**：都市叙述、港乐金曲、跨年龄人生回望（如《陀飞轮》）。
- **核心架构**：年龄/等级档案建档（`LV.18 → LV.55`）-> 青春海滨滑板 -> 写字楼加班与名利阶梯 -> 清单打勾 vs 生命心率倒计时 -> **反向真结局**（卸下所有物质执念，换回日出海岸）。

## 类型 C：悬疑记忆胶片摄影型（往事 / 暗房 / 都市电影感）
- **适用曲风**：温情叙事、怀旧民谣、细腻电影感抒情（如《沙龙》）。
- **核心演出**：旧照片悬念 -> 动态追焦合焦吐出拍立得微景 -> 雨夜擦拭镜头 -> 暗房显影四格回忆 -> 胶片走廊回望首尾呼应。

## 类型 D：戏剧张力逆袭型（孤独 / 抗争 / 聚光灯与爆发）
- **适用曲风**：摇滚流行、强嘶吼高音、舞台感极强曲目（如《浮夸》）。
- **核心演出**：`LV.01 透明人` 躲避冷眼追光 -> 镜面双生对照（聚光狂舞 vs 幕后拭泪）-> 撞碎冷漠高墙站上中心舞台 -> 聚光灭尽留下孤光独白。

## 类型 E：温柔共鸣心事 RPG 型（情绪治愈 / 日常微光 / 陪伴救赎）
- **适用曲风**：钢琴/吉他倾诉开篇、后半段合唱或飙高音释放、关注当代人孤独与自愈心境（如《好想爱这个世界啊》）。
- **核心架构（全曲闭环）**：
  1. **柔和序幕 & 心事档案（0–7s）**：雨夜城市星光下淡入歌名与献辞，转入主角低电量心事面板（`微笑电量 18%`）。
  2. **具象日常切词场景**：昏暗公寓沙发与猫 -> 落日影院白日梦醒 -> 屋檐电线乌鸦议论 -> 雨夜 neon 公交亭违心选择 `▶ “我挺好的呀”`。
  3. **低谷伴行 & 分段高潮递进**：风暴海岬码头伴随旋转灯塔迎来提灯同伴 -> 傍晚海岸电车内景（拉环、睡猫、三层窗外城镇）-> 夕阳河畔手机通讯录 -> 迷雾峡谷吊桥逆行不推人 -> 星空神社湖畔放飞天灯 -> **后半段三段拆解**：午夜雪风立交桥 -> 亮灯面包书店相遇系暖围巾 -> 清晨露台繁花蝴蝶 -> 崇山云海天空步道 -> 全彩樱花流光雨爆发。
  4. **首尾闭环终局**：回到开头一模一样的客厅，此时**夕阳窗帘敞开、温暖斜光铺满地板**，响起最重要的人的来电、`微笑电量 100%` 温柔告别。

## 类型 F：赛博电音 / 浪漫复古 / 国风意境变体（按曲风动态装配）
- **赛博/CityPop/Synthwave（迷幻都市、电子节奏）**：采用紫粉+青蓝双霓虹调色，叠加雨夜高架摩托追逐、霓虹广告牌倒影水洼、黑胶唱片/复古磁带进度条 HUD、节拍音柱频谱地平线。
- **国风/古风/诗意民谣（山河、侠情、离别重逢）**：`320×180` 改用青绿山水/水墨晚霞色板，主角着长衫/披风；道具替换为石拱廊桥、朱红牌坊/鸟居、扁舟渔火、红叶/梅枝飘雪与宣纸风对话框边框。
- **通用首尾闭环设计法则**：无论任何曲风，开头“缺席/未完成/暗色”的核心意象（空座位、未亮起的灯、雨中背影、没拨出的电话），**必须在结尾以温暖对照方式完成呼应**。
