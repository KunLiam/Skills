# 工程红线、高清弹幕规范与成品目录

## 一、七条核心工程与审美红线

1. **严禁“人物与背景二分裂”（风格、透视、颗粒度必须完全一体）**
   - 严禁把高清 AI 透视风景画直接当背景板，再往上面贴简陋方块小人或绿幕硬抠贴片；也严禁无提示强做简陋 Three.js 低模积木。
   - **路线 1（RPG 心事剧场）**：统一在 **`320×180`** 整数像素网格（6× 放大至 `1920×1080`，`imageSmoothingEnabled = false`）绘制场景建筑、光影家具、道具与主角，令主角与环境共用同一套像素粒度和明暗语法。
   - **路线 2（横版视差动作长卷）**：统一 `640×360` 整数倍 3× 放大，至少 4 层（天际 `0.08×` / 远景 `0.22×` / 中景 `0.58×` / 可走地面与主角 `1.00×` / 前景柱影行人 `1.55×`）持续流动。
   - **路线 3（图生视频电影感，需视频模型插件）**：若无图生视频插件，严禁只用 9 张静态大图加 Ken Burns 推拉糊弄。

2. **片头柔和入戏 + 共情文案优先（不要“为了做视频而做”）**
   - 开篇 `0–3s` 必须先做柔和渐入的**曲名序幕**（清晰呈现《歌名》、歌手与温和题记），再过渡进《今日心事/档案卡》，右上角常驻曲名提示。
   - 弱化生硬的街机刷分/COMBO 术语，改用让真实听众眼眶一热的日常细节与心理微抉择（如犹豫后仍按下 `▶ “我挺好的呀”`）。

3. **高可读、零抖动慢速胶囊弹幕系统**
   - 绘制弹幕前显式设置 **`ctx.imageSmoothingEnabled = true`**。
   - 横向位移 **`dx = lerp(W + 40, -tw - 80, u)` 必须保留浮点数，严禁 `Math.round()`**。
   - 跨屏时长放慢至 **`15.0–15.5s`**（字号 `600 22px "PingFang SC"`），**强制加装深色半透明圆角胶囊底衬**（`rgba(8, 12, 26, 0.78)` + `1.2px rgba(155, 185, 240, 0.28)` 描边），避免弹幕滑过像素窗户或竖条霓虹时产生视觉闪烁或看不清文字。
   - 单轨或错峰安全区 **`y = 160`**（避开顶部 `y = 22..130` 的状态栏和右上任务栏，也避开中央剧情角色与 `y = 882..1050` 底部歌词框）。每条间距 `≥ 8s` 保证零重叠。

4. **场景刻画细腻度要求**
   - 室内部落需配齐踢脚线、壁画框、彩色书架、毛毯抱枕、木地板板缝、台灯暖晕及窗外高楼雨点；街景需有砖墙檐角、电线乌鸦、橱窗灯牌、路面水洼霓虹倒影与车尾光轨。

5. **Mac 无头 Chrome 稳定渲染管线**
   - 2D Canvas 管线下，`render.mjs` 使用 `args: ["--disable-gpu", "--no-sandbox"]` 与页面内 `c.toDataURL("image/jpeg", 0.92)`，杜绝 `page.screenshot()` 多进程拼块撕裂；若需启用 WebGL 再显式切换 ANGLE SwiftShader。

6. **音轨母带保真与对齐校验**
   - `ffmpeg` 封装固定 `-c:a aac -b:a 256k`。仅 `--mode preview` 末尾 1.5s 音画微淡出；`--mode full` 完整保留原曲尾奏，切勿沿用错版或 DJ 剪辑轴。

7. **先抽帧拼图验收，再拉试看与全片**
   - 任何修改后先跑 `--mode keyframes` 导出覆盖首尾转折的关键帧，`ffmpeg tile` 拼图后用 `read_file` 逐帧细查无遮挡/无重叠，清理 `/tmp/` 后再渲染 MP4 并跑 `ffprobe` 校验输出规格。
