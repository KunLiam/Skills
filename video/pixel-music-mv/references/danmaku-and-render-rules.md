# 工程红线、四层像素建模与高清防抖规范

## 一、八条核心工程与审美红线

1. **严禁“人物与背景二分裂”（风格、透视、颗粒度完全一体）**
   - 严禁将高清 AI 透视风景画作直接贴背景，上面硬浮方块小人或绿幕抠像；亦严禁无铺垫堆砌简陋低模 3D 盒子。
   - **路线 1（RPG 剧场）**：所有场景、建筑、光影家具、道具与人物统一绘制在 **`320×180`** 像素画布（`imageSmoothingEnabled = false`，6× 整数倍放大至 `1920×1080`），顶层仅文字气泡、选择框、HUD 与弹幕用原生 `1080p` 抗锯齿渲染。
   - **路线 2（横版视差动作长卷）**：统一 `640×360` 整数倍 3×，保持 4–5 层连续视差与同粒度绘制。

2. **片头柔和入戏 + 共情文案优先**
   - `0–3s` 先柔和渐入**曲名序幕**（清晰呈现《歌名》、原唱、氛围微题记），再过渡进档案/序章。
   - 用真实细腻的日常动作与心理微抉择（如在通讯录名字间犹豫后收起手机）取代冷冰冰的街机 COMBO/HP 刷分词。

3. **四层像素世界建模标准（杜绝单调纯色块与“后半段空洞”）**
   每一幕画面必须具备以下 4 个纵深层次，**严禁只画“天空渐变 + 一条直线地板 + 孤零零一个角色”**：
   - **L1 天空层**：多色阶天光渐变 + 轻微棋盘格过渡 dithering + 像素星辰/体积斜射光束（用贴合窗口的半透明梯形而非碎方块）+ 分层亮/暗面雕塑云朵（`pxCloud`）。
   - **L2 远景层**：带右侧阴影面的不对称起伏山峦（`pxMountains`）与错落亮窗、水塔、天线的城市天际线（`pxCitySkyline`）。
   - **L3 中景道具与建筑**：
     - 室内标配：踢脚线、画框、时钟、满格书籍与仙人掌书架、台灯暖光晕、毛毯边桌、沙发睡猫；
     - 室外标配：拱门石柱+悬灯、店铺条纹雨棚与温暖橱窗、带旋转光束的灯塔与摇晃渔船、铁艺护栏与吊桥拉索、旋转远景风车、鸟居/樱花树冠（树干加根部阴影与分簇亮面）。
   - **L4 近景地面与生态动态**：使用带砖缝与水洼霓虹倒影的铺装路（`pxPavedGround`）、随风起伏的草丛与多瓣像素花朵（`pxGrassMeadow`），配飘落花瓣/雪花/枫叶/天灯火光/蝴蝶微粒。

4. **反静止节奏律（单背景持有 `≤ 12–15s`）**
   - 主角不能长时段呆站屏幕中央；静止/走路必须伴有**眨眼（每 ~3.5s）、呼吸轻微起伏、围巾随风飘动、手机屏幕照亮脸部**等生命细节。
   - 任何持续超过 `15s` 的长桥段或终章高潮（如 40s 大副歌），**必须按词意拆分成 2–3 个递进舞台**（场景构图、天气光影、同屏人物站位与视差速度随句演化）。

5. **高可读、零抖动慢速胶囊弹幕系统**
   - 绘制弹幕前显式开启 `ctx.imageSmoothingEnabled = true`。
   - 横向位移 **`dx = lerp(W + 40, -tw - 80, u)` 保持精确浮点，严禁 `Math.round()`**。
   - 跨屏时间设为 `14.5–15.5s`（`600 22px "PingFang SC"`），强加圆角深色胶囊底衬（`rgba(8, 12, 26, 0.78)` + 微描边），安全通行区固定于 `y = 160`（零遮挡顶栏 HUD 与中央主角），相邻弹幕间隔 `≥ 8–10s`。

6. **Mac 无头 Chrome 稳定导出**
   - 2D Canvas 下使用 `args: ["--disable-gpu", "--no-sandbox"]` 与页面内 `canvas.toDataURL("image/jpeg", 0.92)` 逐帧导出，杜绝截屏拼块撕裂。

7. **音轨保真与先抽帧拼图验收**
   - `ffmpeg` 封装固定 `-c:a aac -b:a 256k`。`--mode full` 完整保留原曲尾奏，绝不做未授权截断。
   - 每次修改必先 `--mode keyframes` + `ffmpeg tile` 拼图，用 `read_file` 亲眼核对无气泡遮挡、无背景空白，清理 `/tmp/` 后再拉全片并用 `ffprobe` 校验。

8. **原版音轨歌词对齐与“飙高音不断档”铁律（必查！）**
   - 禁止盲信下载目录附带的残缺/占位 `.lrc`（如 `该歌曲暂无歌词`）或网上不同时长的 Live 版歌词时间轴。
   - 必跑 `scripts/sync_lyrics.py`：**优先提取音频自带的 `163 key` (`musicId`) 与精准毫秒时长**校验官方原版 LRC，并在 `mid - 1.1*side` 人声隔离频段上对比每句起音 `pre -> on` 跃升。
   - **高音/吟唱长音防消失规则**：当歌手在某句结尾连续飙高音或长吟唱（即使 LRC 插入空行时间戳），或句间换气间隔 `< 5.5s` 时，**当前歌词必须持续稳稳显示在对话框内直至下一句唱词开口**，绝不在高音拉长到一半时切回空旁白导致观感不同步！
