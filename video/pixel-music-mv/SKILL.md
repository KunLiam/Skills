# 通用像素音乐 MV 创作引擎 (`pixel-music-mv`)

> **核心理念**：无论用户提供抒情治愈、摇滚燃曲、都市哲思、赛博电音还是古风民谣，画面、人物粒度、节拍运镜、交互心理与歌词同步必须**浑然一体**——先对准原曲呼吸，再雕琢四层像素世界，让观众瞬间代入并听到哪句就看到哪句。

---

## 一、制片路线总览（开动前必先依据歌曲特征定型）

绝不可把高清写实背景图与粗糙方块小人强行拼贴（二分裂感）；亦严禁未装视频生成插件时拿静止插画配推拉镜冒充 MV：

1. **路线 1 · `320×180` 像素人生 RPG 共鸣剧场（默认首选 · 强叙事/都市/治愈/哲思）**
   - **渲染标准**：**`320×180` 整数网格（`imageSmoothingEnabled = false` 6× 无锯齿放大至 `1920×1080`）** 绘制背景、建筑、环境光效与角色，顶层叠加 `1080p` RPG 状态栏、微笑/生命进度条、名牌对话框、心理抉择菜单与微气泡。
   - **共情开篇**：`0–3s` 先柔和淡入**曲名序幕**（歌名、原唱、贴合词意的题记），`3–7s` 过渡进主角心事建档，再进入剧情第一幕。

2. **路线 2 · `640×360` 横版多速视差探索长卷（快节奏/成长/燃向/奔跑冒险）**
   - **渲染标准**：`640×360` 整数 3× 至 `1920×1080`，至少 4–5 速滚动视差层（天际 `0.08×` / 远山天际线 `0.22×` / 中景建筑林木 `0.55×` / 可走地面与主角 `1.00×` / 前景剪影柱影 `1.55×`），每乐章轮换核心机制，详见 [创意玩法组件库](references/mechanics-library.md)。

3. **路线 3 · 图生视频一体化映画（仅限已安装 Kling AI / Veo 等视频生成插件）**
   - 先生成画风/人设严格统一的 16:9 像素原画关键帧，再转真动画后剪辑封装。

## 二、标准化四阶段工作流

### 阶段 1：音源真相校验、精确词轴与高音不断档（严禁凭印象估时间）
1. **LRC 有效性审计（防假词/错版音轨）**：
   - 检查用户提供 `.lrc`：若为空、仅含占位符（如 `该歌曲暂无歌词`）、或末尾时间与音频真实时长不一致，**严禁手猜时间轴**！
   - 若为网易云音频（含 `163 key` 标签），运行 `sync_lyrics.py` 自动反解 `musicId`、校验对应原版官方 LRC 并按 `mid - 1.1*side` 人声频段能量核对每一句 `pre -> on` 起音跃升：
   ```bash
   python3 /Users/SEI/.gemini/config/skills/pixel-music-mv/scripts/sync_lyrics.py <音频路径> [-l <歌词.lrc>] -o mv/lyrics.js
   python3 /Users/SEI/.gemini/config/skills/pixel-music-mv/scripts/analyze_song.py <音频路径> -o song-analysis.json
   ```
2. **高音拉长与短呼吸防断档铁律**：
   - LRC 中的空行 `[mm:ss.xx]` 常用于标记“间奏”或“副歌尾字飙高音/长吟唱”。当 `vocals` 在空行后持续发声（高音/吟唱未断，例如“别怕 别怕”或“这世界突然填满色彩”后半段飙高音），**歌词必须继续稳定保留在屏幕直至下一句开口（或彻底进入纯乐器长间奏 `>= 5.5s` 无声期）**，绝不能在高音唱到一半时切走或闪出旁白！
3. **曲风与原型路由**：按 [六大曲风与叙事原型库](references/style-archetypes.md) 匹配整片色调脚本（Color Script）、主角衣着道具及**首尾呼应闭环**。

### 阶段 2：四层像素建模、动态节奏与胶囊防抖弹幕
1. **消除画面空洞感的四层像素建模标准**：哪怕是 `320×180`，每一幕都必须自带**纵深四层结构**与环境生态：
   - **远天层**：多色阶天光渐变 + 像素星辰/体积光束 + 手工雕塑云团（`pxCloud`）；
   - **远景层**：带阴影斜坡的不规则起伏山脊（`pxMountains`）与层次天际线灯火（`pxCitySkyline`）；
   - **中景道具层**：室内需配书架、绿植、挂画、时钟、台灯暖晕与猫/宠物；室外需配砖拱桥柱、街角条纹雨棚、灯塔光束、神社鸟居、公交站牌或铁路电线；
   - **近景地面与生态**：严禁大面积纯色单色块地面！需用砖缝与湿润霓虹水洼（`pxPavedGround`）、随风摆动草花（`pxGrassMeadow`）、光晕街灯（`pxStreetLamp`）、花瓣/落叶/天灯/蝴蝶持续填充生机。
2. **反单调换场律（10–15s 上限）**：任何单幕静止底图不得持续超过 `10–15s`。长副歌/长桥段（如 30–45s）必须拆为 **2–3 个随歌词情绪演进的场景递进**（如：寒风夜桥 -> 暖灯相遇 -> 清晨花坡；拨开乌云 -> 跨越长桥 -> 樱花繁花全彩爆发）。
3. **高清胶囊防抖弹幕**：严格遵循 [工程红线与避坑手册](references/danmaku-and-render-rules.md)（`15.5s` 慢速漂浮、深色半透明胶囊底衬、`ctx.imageSmoothingEnabled = true`、浮点 `dx` 位移、单轨 `y = 160` 避让所有 UI）。

### 阶段 3：抽帧拼图验收 + 45s 试看
1. 每次修改渲染或时间轴，必跑覆盖全片高潮与高音段的关键帧抽检并拼 `4×4` / `5×2` 接触表，用 `read_file` 亲眼核查后再清 `/tmp/`：
   ```bash
   ./一键生成.sh --mode keyframes --times <覆盖起止/转场/飙高音时间点> --out /tmp/mv_kf
   ffmpeg -y -pattern_type glob -i '/tmp/mv_kf/t*.jpg' -filter_complex "scale=480:270,tile=4x4:padding=4:color=0x111111" /tmp/mv_sheet.jpg
   ```
2. 新歌首次交付先出 `--mode preview --duration 45` 请用户确认风格与节奏，再拉整片。

### 阶段 4：全片封装、真片核验与 Skill 持续进化
1. 使用 `--mode full --workers 8` 渲染并 `ffprobe` 校验音画时长、帧率（`30fps`）、码率及 `AAC 256k / 48kHz` 完整性。
2. 每次新曲踩坑或美学突破，顺手记入 [迭代日志](references/iteration-log.md) 并保持双边镜像目录一致。

## 工具脚本清单 (`scripts/`)
- `scripts/sync_lyrics.py` — LRC 审计、音频 `163 key` 反解拉取、人声能量比对与高音不断档 `lyrics.js` 生成
- `scripts/analyze_song.py` — 音频 BPM、节拍点、段落结构与重音检测
- `scripts/check_env.py` — 检查 ffmpeg / Node / librosa 环境
- `scripts/srt2js.py` — `.srt` 字幕转 `lyrics.js`
- `scripts/contact_sheet.py` — 生成带时间码的视频抽帧审片表
- `scripts/video_rhythm.py` — 量化镜头切点频率与静止率
- `scripts/finalize_audio.py` — 保持母带响度无损封装音轨
