# 像素音乐 MV 统一创作与重制引擎 (`pixel-music-mv`)

> **核心理念**：观众点开像素 MV，是为了在音乐、画面、微交互与共鸣文案里**代入故事**，绝不能为了炫技堆砌无关小游戏，更严禁用静态插画加推拉镜头当动画 MV。

---

## 一、制片路线总览（开动前必选定唯一主路线）

根据歌曲题材与可用工具环境，严格从以下路线择一执行，**绝不可把高清写实背景图与粗糙方块小人强行拼贴（二分裂感）**：

1. **路线 1 · 像素人生 RPG 共鸣剧场（默认首选 · 标杆：《陀飞轮-抖音》《好想爱这个世界啊》）**
   - **适用**：都市情感、人生回顾、抑郁/孤独治愈、强叙事抒情曲。
   - **渲染标准**：使用 **`320×180` 纯净统一像素网格（6× 整数倍无锯齿放大到 `1920×1080`）** 绘制场景、角色、光影与细节道具，并在 `1080p` 顶层叠加锐利精致的 RPG 金框状态栏、心情进度条、名牌打字机歌词框、选择菜单与情绪气泡。
   - **共情铁律**：`0–3s` 必须先有**柔和曲名序幕**（点明歌名、原唱与献辞），再柔和淡入主角心事建档；全程多用贴近普通人心境的选择分支与环境微动态，避免生硬“COMBO/刷怪”机械词。

2. **路线 2 · 横版多速视差探索长卷（标杆：《向阳而生》《风之海》）**
   - **适用**：快节奏成长、宏大冒险、自然奔跑飞行。
   - **渲染标准**：统一在 `640×360`（3× 至 `1920×1080`）或统一像素网格下构造 4–5 速滚动视差层（远空/建筑/街景/可走地面/前景遮挡掠影），严禁连续两段重复“跳云台/跳青苔”，每乐章轮换机制见 [创意玩法组件库](references/mechanics-library.md)。

3. **路线 3 · 图生视频一体化映画（仅当环境已安装 Kling AI / Veo 等视频生成插件）**
   - 先绘制风格/人设完全一致的 16:9 像素原画关键帧，再交由视频模型生成真实眨眼/微风/走路动作，最后剪辑配乐封装。**未安装视频插件时，绝不用纯静止大图仅靠推拉缩放冒充动画 MV。**

## 二、标准化四阶段工作流

### 阶段 1：音源校验、词意解构与全曲闭环脚本
1. **音频与真实人声校验**：优先使用无损 `.flac`/母带，运行分析脚本确认 BPM 与人声起落，校准 `lyrics.js` 每句精准起止（长间奏/高音吟唱/尾奏单独编排过场画面，不能黑屏或干等）：
   ```bash
   python3 /Users/SEI/.gemini/config/skills/pixel-music-mv/scripts/analyze_song.py <音频路径> -o song-analysis.json
   ```
2. **原型定型**：参照 [风格与原型库](references/style-archetypes.md) 确定主线隐喻与首尾呼应彩蛋（如开头“无人拨打的手机/昏暗房间”对应结尾“夕阳下接通的来电”）。
3. **落盘分镜与全曲文案清单**：逐句对应歌词时间轴写清场景细节、环境光影、心理选择框文案及慢速共鸣弹幕（每 `10–13s` 一条，全曲约 `18–25` 条）。

### 阶段 2：精致像素世界与防抖字幕/弹幕编码
1. **场景细节与一体感**：哪怕是 `320×180` 像素画，室内也要有踢脚线、书架、壁画、门窗反光与台灯晕影；街头要有砖缝、屋檐瓦片、霓虹倒影与车流尾迹。
2. **高清平滑弹幕 & 排版**：严格遵循 [工程红线与避坑手册](references/danmaku-and-render-rules.md)（慢速 `15.5s` 巡航、深色毛玻璃胶囊底衬、浮点坐标防抖、避开顶部左右 HUD 状态框与底部字幕区）。

### 阶段 3：抽帧质检 + 45s 试看验收
1. 修改渲染逻辑后，必须按序输出覆盖各幕转折点的关键帧并拼接接触表审查：
   ```bash
   ./一键生成.sh --mode keyframes --times <时间点列表> --out /tmp/mv_kf
   ffmpeg -y -pattern_type glob -i '/tmp/mv_kf/t*.jpg' -filter_complex "scale=480:270,tile=5x2:padding=6:color=0x111111" /tmp/mv_sheet.jpg
   ```
   用 `read_file` 亲眼确认：**曲名序幕柔和、场景细节饱满、人物踏实坐/立于家具路面、弹幕气泡零重叠、歌词全无截断**。随后清理 `/tmp/`。
2. 跑 `--mode preview --duration 45` 交付用户验收节奏与画风后再拉全片。

### 阶段 4：全片交付与 Skill 持续进化
1. 使用 `./一键生成.sh --mode full --workers 8` 导出完整 1080p `30fps` + 256k AAC 成片并用 `ffprobe` 校验。
2. 将实战经验同步追加到 [迭代日志](references/iteration-log.md) 与对应规则文件，并同步更新仓库镜像（如有）。

## 工具脚本清单 (`scripts/`)
- `scripts/analyze_song.py` — 音频 BPM、结构分段、人声能量跃升分析
- `scripts/check_env.py` — 检查 Python/librosa/ffmpeg/Node.js 环境
- `scripts/srt2js.py` — 将 `.srt`/`.lrc` 转为前端 `lyrics.js`
- `scripts/contact_sheet.py` — 生成带时间戳的视频抽帧接触表
- `scripts/video_rhythm.py` — 量化镜头切换节奏与画面静止率
- `scripts/finalize_audio.py` — 保持原曲响度无损封装音轨
