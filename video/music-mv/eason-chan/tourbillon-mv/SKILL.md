# 陀飞轮「人生闯关」像素 MV 专属 Skill

## 一键工具包目录

位于本 Skill 同级的 [`kit/`](kit/) 目录：
- `kit/full_mv_game.html` — 17 阶段 Canvas 2D 游戏化 MV 引擎（`1920×1080`，`30fps`，支持 URL 参数 `?player=姓名`）
- `kit/lyrics.js` — 精确歌词时间轴（`0:00 – 4:38`）
- `kit/assets_v3/` — 16 张 16:9 港风像素插画底图（`scene1` – `scene16`）
- `kit/song.mp3` — 原曲音频
- `kit/render.mjs` — 跨平台并行帧渲染 + `ffmpeg` 自动封装与混音脚本
- `kit/一键生成.sh` / `kit/一键生成.bat` — macOS/Linux 与 Windows 一键启动脚本

## 标准执行流程

> **重要**：Chrome 无头模式禁止 `file://` 加载本地资源，必须通过 `render.mjs`（本地 `127.0.0.1` HTTP 服务）渲染。

### 1. 一键生成（不改代码，直接出片或换主角名）

```bash
cd kit

# 完整版 4:38（约 8-10 分钟，默认主角：坤仔）
./一键生成.sh --player 坤仔

# 42 秒快速试看
./一键生成.sh --mode preview --player 坤仔

# 17 关键帧快速验收（约 5 秒）
./一键生成.sh --mode keyframes --player 坤仔
```

### 2. 二创修改工作流（改玩法 / 卡片 / 文案 / 歌词）

1. 按下方「17 阶段速查表」定位 `kit/full_mv_game.html` 对应渲染函数或 `kit/lyrics.js`。
2. 修改后先跑 `./一键生成.sh --mode keyframes --player <姓名>` 检查 17 张关键帧无文字重叠、无模糊抖动，再跑全篇。
3. 工程红线：
   - 移动中的任务卡/弹幕必须使用 `Math.round()` 整数像素坐标对齐，避免亚像素抖动。
   - 高亮底图上的文字必须配深色半透明圆角底框（`rgba(12,14,24,0.90)`）。
