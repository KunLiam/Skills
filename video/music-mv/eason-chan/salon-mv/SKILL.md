# 陈奕迅《沙龙》悬念互动像素 MV 专属 Skill

## 独立一键工具包位置

`/Users/SEI/Desktop/liangkun/Video/沙龙MV_一键工具包/`

核心文件：
- `full_mv_pixel.html` — 15 阶段「35mm 悬念互动摄影微游戏合集」Canvas 2D 引擎（`1920×1080`，`30fps`，支持 URL 参数 `?player=姓名`）
- `lyrics.js` — 精确简体歌词时间轴（`0:00 – 4:32`）
- `assets_px/` — 20 张 16:9 定制 32-bit 港风电影感像素底图（`px_salon_s01` – `px_salon_s20`）
- `song.mp3` — 精修原曲音频（`272.0s`）
- `render.mjs` — 跨平台并行帧渲染 + `ffmpeg` 自动封装与混音脚本
- `一键生成.sh` / `一键生成.bat` — macOS/Linux 与 Windows 一键入口

## 标准执行流程

> **重要**：Chrome 无头模式禁止 `file://` 加载本地资源，必须通过 `render.mjs`（本地 `127.0.0.1` HTTP 服务）渲染。

### 1. 一键生成（不改代码，直接出片或换主角名）

```bash
cd /Users/SEI/Desktop/liangkun/Video/沙龙MV_一键工具包

# 完整版 4:32（默认摄影师：坤仔）
./一键生成.sh --player 坤仔

# 45 秒快速试看
./一键生成.sh --mode preview --player 坤仔

# 20 关键帧快速验收（约 4 秒）
./一键生成.sh --mode keyframes --player 坤仔
```

### 2. 二创修改工作流

1. 按下方「15 阶段时间轴速查表」定位 `full_mv_pixel.html` 对应微游戏函数或 `lyrics.js`。
2. 修改后先跑 `./一键生成.sh --mode keyframes --player <姓名>` 检查构图与拍立得文字无溢出、无重叠，再跑 `--mode preview` 或完整版。
3. 工程红线：
   - 所有移动元素与卡片坐标必须使用 `Math.round()` 对齐，拍立得底部文字使用 `maxWidth = pw` 自适应防溢出。
   - 关卡切换采用双层同步动态叠化（`slide` 缩放漂移、`leak` 暖金光晕、`flash` 快门闪切），两层在转场期间同时保持动画。
