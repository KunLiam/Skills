# 陈奕迅《沙龙》35mm 悬念互动像素 MV 一键工具包

将陈奕迅《沙龙》（4:32）改编为 **15 阶段 · 20 张独立 32-bit 港风电影感像素场景**「第 36 张底片 · 悬念互动微游戏合集」1080p 30fps 代码渲染 MV，支持直接打包发给别人一键出片，也支持自定义摄影师姓名（默认「坤仔」）。

## 环境要求

- **Node.js 18+**
- **ffmpeg**（macOS 可执行 `brew install ffmpeg`）
- **Chrome / Chromium / Edge** 任意其一（或通过环境变量 `CHROME_PATH` 指定）

## 一键使用

### macOS / Linux

```bash
# 1. 一键生成完整版 4:32（默认摄影师：坤仔）
./一键生成.sh

# 2. 自定义摄影师名字
./一键生成.sh --player 追风少年

# 3. 仅渲染前 45 秒快速试看
./一键生成.sh --mode preview

# 4. 仅导出 20 张关键帧用于快速验收构图（约 4 秒）
./一键生成.sh --mode keyframes
```

### Windows

双击 `一键生成.bat` 即可生成完整版；或在命令行传参：

```cmd
一键生成.bat --player 坤仔 --mode preview
```

## 目录结构

| 文件 / 目录 | 说明 |
|---|---|
| `full_mv_pixel.html` | 15 阶段「悬念互动摄影微游戏」核心渲染引擎（第一视角裂像对焦、探照寻踪、命运抉择、实景拍立得、Undertale 弹幕战、暗房显影、沙龙画展） |
| `lyrics.js` | 精准对齐的简体歌词时间轴（0:00 – 4:32） |
| `assets_px/` | 20 张 16:9 定制 32-bit 港风电影感像素底图 |
| `song.mp3` | 精修原曲音频（272.0s，已平滑淡出收尾） |
| `render.mjs` | 跨平台并行帧渲染 + ffmpeg 音视频封装脚本 |
| `一键生成.sh` / `一键生成.bat` | macOS/Linux 与 Windows 一键启动脚本 |
