# 华晨宇《风之海》像素 RPG MV 专属 Skill

## 独立一键工具包位置

`/Users/SEI/Desktop/liangkun/Video/风之海MV_一键工具包/`

核心文件：
- `full_mv_pixel.html` — 21 阶段 Canvas 2D 像素 RPG 引擎（`1920×1080`，`30fps`，支持 URL 参数 `?player=姓名`）
- `lyrics.js` — 精确简体歌词时间轴（`0:00 – 5:03`）
- `assets_px/` — 20 张 16:9 定制 32-bit 像素插画底图（`px_wind_s1` – `px_wind_s20`）
- `song.mp3` — 精修原曲音频（`303.0s`，已裁去尾部无关声音并加 3.5s 平滑淡出）
- `render.mjs` — 跨平台并行帧渲染 + `ffmpeg` 自动封装与混音脚本
- `一键生成.sh` / `一键生成.bat` — macOS/Linux 与 Windows 一键入口

## 标准执行流程

> **重要**：Chrome 无头模式禁止 `file://` 加载本地资源，必须通过 `render.mjs`（本地 `127.0.0.1` HTTP 服务）渲染。

### 1. 一键生成（不改代码，直接出片或换主角名）

```bash
cd /Users/SEI/Desktop/liangkun/Video/风之海MV_一键工具包

# 完整版 5:03（默认主角：追风少年）
./一键生成.sh --player 追风少年

# 45.5 秒快速试看
./一键生成.sh --mode preview --player 追风少年

# 22 关键帧快速验收（约 5 秒）
./一键生成.sh --mode keyframes --player 追风少年
```

### 2. 二创修改工作流

1. 按下方「21 阶段时间轴速查表」定位 `full_mv_pixel.html` 对应渲染函数或 `lyrics.js`。
2. 修改后先跑 `./一键生成.sh --mode keyframes --player <姓名>` 检查 22 张关键帧无文字重叠、无抖动，再跑 `--mode preview` 或完整版。
3. 工程红线：
   - 所有移动卡片与拾取提示必须使用 `Math.round()` 整数坐标对齐，且拾取提示画在角色上方，避免遮挡角色。
   - 场景切换通过 `drawCloudWipe()` 像素云幕横扫衔接，保持全程连贯性。
