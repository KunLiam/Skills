# 华晨宇《风之海》像素 RPG MV 专属 Skill

## 一键工具包目录

位于本 Skill 同级的 [`kit/`](kit/) 目录：
- `kit/full_mv_pixel.html` — 14 阶段三幕剧 Canvas 2D 像素 RPG 引擎（`1920×1080`，`30fps`，支持 URL 参数 `?player=姓名`）
- `kit/lyrics.js` — 精确简体歌词时间轴（`0:00 – 5:34`）
- `kit/assets_px/` — 13 张 16:9 定制 32-bit 像素插画底图（`px_wind_s1` – `px_wind_s13`）
- `kit/song.mp3` — 原曲音频
- `kit/render.mjs` — 跨平台并行帧渲染 + `ffmpeg` 自动封装与混音脚本
- `kit/一键生成.sh` / `kit/一键生成.bat` — macOS/Linux 与 Windows 一键启动脚本

## 标准执行流程

> **重要**：Chrome 无头模式禁止 `file://` 加载本地资源，必须通过 `render.mjs`（本地 `127.0.0.1` HTTP 服务）渲染。

### 1. 一键生成（不改代码，直接出片或换主角名）

```bash
cd kit

# 完整版 5:34（默认主角：追风少年）
./一键生成.sh --player 追风少年

# 45.5 秒快速试看
./一键生成.sh --mode preview --player 追风少年

# 16 关键帧快速验收（约 3 秒）
./一键生成.sh --mode keyframes --player 追风少年
```

### 2. 二创修改工作流

1. 按下方「14 阶段时间轴速查表」定位 `kit/full_mv_pixel.html` 对应渲染函数或 `kit/lyrics.js`。
2. 修改后先跑 `./一键生成.sh --mode keyframes --player <姓名>` 检查 16 张关键帧无文字重叠、无抖动，再跑全篇。
3. 工程红线：
   - 移动卡片与拾取提示必须使用 `Math.round()` 整数坐标对齐，拾取提示绘制在角色上方避免遮挡。
   - 场景切换通过 `drawCloudWipe()` 像素云幕横扫衔接。
